# Kriptia Programming Language (`kriptia-lang`)

Kriptia es un lenguaje de programación moderno, de propósito general y **100% nativo**, diseñado desde cero en C++ para ofrecer un rendimiento óptimo sin depender de intérpretes externos como Python. Permite desarrollar desde scripts y utilidades hasta software de sistema de forma totalmente independiente.

## 🚀 Instalación Global (Termux y Linux)

Cualquier persona puede instalar Kriptia en su terminal ejecutando una sola línea:

```bash
curl -sSL [https://raw.githubusercontent.com/arencibiayaisel/kriptia-lang/main/install.sh](https://raw.githubusercontent.com/arencibiayaisel/kriptia-lang/main/install.sh) | bash
